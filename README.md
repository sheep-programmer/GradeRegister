# 成绩登记系统

面向老师的语音成绩录入工具。打开成绩 Excel，念学生姓名自动定位到对应行，念各题得分自动填入，总分自动计算；再念一遍自己算的总分与软件核对，不一致就在该行标红。

语音全程本地离线识别，录音数据不出本机。支持 macOS 与 Windows。

首次运行会下载中文识别模型（默认 sense-voice 约 228MB，带进度条），下完才能开始说话，之后完全离线。也可以换 paraformer（约 217MB，短句更快）。

模型从 huggingface 下载，访问慢或不通时会自动改用镜像；有自己的镜像可以设环境变量 `HF_ENDPOINT`。
模型状态在「设置 → 语音」里看得到，也可以在那里手动下载或换引擎。

## 功能

| 场景 | 做法 |
|---|---|
| 定位学生 | 念「张三」，表格跳到该行并高亮；发音接近的两个名字（刘洋／刘阳）会弹窗让你点选，不替你瞎猜 |
| 按号码定位 | 念「5号」。表里有学号列就按学号，没有就按名单第几位。念错号码会明确报错，不会填到别人头上 |
| 填分数 | 念「第一题十八分」按题号填；表头叫别的名字就直接念表头，「程序题72分」一样填得进去 |
| 一口气念完 | 「第一题十分第二题二十分第三题三十分」一句话填完整行 |
| 念错重填 | 对同一题再念一次直接覆盖；一句话填的多个分数，撤销一次全退回 |
| 总分核对 | 念「总分 62」与软件算出的值对比，一致写 ✓，不一致标红「不一致」 |
| 切到下一位 | 录完一位说「下一个／下一位／继续」直接跳到下一位还没录完的学生；名单里有同音姓名（如「纪旭」）时优先按名字处理 |
| 手动兜底 | 双击单元格直接改；右键可清除单格／整行／整列，Delete 键清除选中区域 |
| 数据安全 | 首次打开自动备份到 `backups/`（保留最近 20 份），默认每填一个分数就写回 |

## 安装

### 方式一：下载现成的程序（推荐给不折腾的人）

到本仓库的 [发行版](../../releases) 页面下载，**不用装 Python、不用装依赖、不用联网**，默认语音模型已经打进程序里：

- **Windows**：下载后解压，双击文件夹里的 `GradeRegister.exe`
- **macOS**：下载 `.dmg`，拖进「应用程序」。首次打开右键点图标 →「打开」→ 再点「打开」（因为没买苹果开发者签名）

首次录音时系统会问麦克风权限，**必须点允许**。

想自己打包见 [打包说明.md](打包说明.md)。

### 方式二：从源码运行

需要 **Python 3.9+**（含 tkinter）。

**macOS**：双击 `启动.command`
**Windows**：双击 `启动.bat`

首次运行会自动创建虚拟环境、安装依赖、准备语音模型。

手动安装：

```bash
pip install -r requirements.txt
python main.py --check     # 环境自检
python main.py             # 启动
python main.py 成绩表.xlsx  # 启动并直接打开某份表格
```

> macOS 若提示缺少 tkinter：`brew install python-tk@3.12`
> Windows 使用 python.org 官方安装包自带 tkinter，无需额外操作。

## 使用

1. **打开表格**：点右上角「打开表格」选 `.xlsx`。程序自动识别姓名列、题号列、总分列，并在总分列右边补一列「核对」。
2. **念姓名**：点「开始说话」进入连续听写，念「张三」，稍停即自动跳到该行。
3. **念分数**：接着念「第一题十八分」「第二题十二分」，或者「18加12加15加17」。填到哪一题，表格里那一格会标黄提示。
4. **核对总分**：念「总分 62」。一致写 ✓；不一致在核对列标红，说明有题念错或听错，可以撤销重录。
5. **切下一位**：念「下一个」「下一位」或「继续」直接切到下一位还没录完的学生，不用重念名字；也可以在设置里开「录完自动切下一位」，核对完自动切换。接着循环往复。

按住空格键也能说话（需在设置里开启「按住说话」）。

### 表格格式

第一行是表头：

| 姓名 | 第一题 | 第二题 | 第三题 | 第四题 | 总分 |
|---|---|---|---|---|---|
| 张三 | 18 | 12 | 15 | 17 | =SUM(...) |

- 姓名列：表头含「姓名/名字/学生」，找不到则用第一列
- 题号列：姓名列与总分列之间，表头含「题」或为纯数字
- 总分列：表头含「总分/总成绩/总计/合计」，找不到则用最后一列
- 核对列：总分列之后表头含「核对/核查/复核/检查/确认」的列，没有就自动新建
- 只支持 `.xlsx`；老版 `.xls` 请在 Excel/WPS 里另存为 `.xlsx`
- 表头不必在第一行，上方可以有标题行或空行
- 总分列不必在最右边
- 运行 `python make_instance.py` 可生成一张空的实例表（内含两位「张三」演示重名确认）

## 设置

点右上角「设置」，保存到 `config.json`。

| 配置项 | 说明 |
|---|---|
| 语音引擎 | `sense-voice`（默认，整句解码，最准，模型 228MB）/ `paraformer`（整句解码，短句更快，对「姓名+分数」连读不丢字，模型 217MB）/ `sherpa`（边说边出字，会把学生名单自动写进热词，念姓名更准）/ `vosk`（模型仅 42MB）/ `faster-whisper`（慢，需 `pip install faster-whisper`） |
| 麦克风 | 默认「自动选择」，每次启动挑一个真正收得到声音的设备；也可以手动指定 |
| 断句停顿 | 连续听写时说完一句停顿多久就自动识别；`sherpa` 自带端点检测，这一项对它不起作用 |
| 剥离题号前缀 | 念「第一题18分」时只取 18 |
| 剥离「分」后缀 | 念「18分」时取 18。**别关**：关掉后连念「3分4分5分」只会取到最后一个 |
| 总分写公式 | 总分列写 `=SUM()`，关闭则写算好的数值 |
| 一致写 ✓ | 关闭则只标不一致 |
| 自动保存 | 四选一：总分核对通过才存（默认）/ 每填一个分数就存 / 每录完一名学生存 / 只在点「保存」时写盘 |
| 录完自动切下一位 | 核对完总分一致后自动选中下一位还没录完的学生；不开则念「下一个」手动切 |
| 按住说话 | 默认关闭（点一下开始、再点一下结束）；开了之后按住按钮或空格说话，松手识别 |
| 提示音 | 默认关闭。开了之后填分、核对通过、核对不一致、没听清各有不同的声音 |

## 项目结构

```
GradeRegister/
├── main.py                    入口（--check 环境自检）
├── download_model.py          下载当前引擎所需的语音模型
├── make_instance.py           生成空的实例成绩表
├── 启动.command / 启动.bat     双击启动脚本
├── models/                    语音模型
├── backups/                   原表自动备份
├── tests/                     单元测试与界面冒烟测试
└── grade_app/
    ├── state.py               状态机：选学生 → 填分 → 核对总分
    ├── parser.py              中文数字、分数提取、姓名匹配与拼音纠错
    ├── excel_io.py            Excel 读写、公式、标红、备份
    ├── speech.py              语音引擎（sense-voice / paraformer / sherpa / vosk / faster-whisper）
    ├── recorder.py            录音线程、自动增益、断句
    ├── platform_support.py    平台差异（字体、DPI、右键、默认程序）
    ├── config.py              默认配置与读写
    ├── gui.py                 界面入口
    └── ui/
        ├── theme.py           设计令牌与 ttk 样式
        ├── widgets.py         圆角按钮、电平表、提示条、识别记录、进度点
        ├── dialogs.py         选择学生、设置、使用说明
        └── main_window.py     主窗口
```

运行测试：

```bash
python -m unittest discover tests
```

界面冒烟测试需要图形环境，无头环境下会自动跳过。

## 常见问题

**念了名字没反应**
先看左下角是否显示「已就绪」。说话前后各留半秒，太短会识别为空。

**名字识别不准**
弹窗会列出发音相近的候选，点选即可；也可以双击单元格直接打字。

**分数填错了**
对同一题重念一次会直接覆盖；或点「撤销」，或右键该行「清空该生已填分数」。

**总分不一致**
软件把听到的各题分数求和，与你报的总分对不上，说明有题念错或听错，核对列已标红方便复查。

**完全没有声音**
点「帮助 → 麦克风没声音？」，里面有按当前系统给出的权限设置步骤，并可一键跳转到系统设置页。

**保存失败**
表格正被 Excel 打开时无法写入，关掉 Excel 再点保存。
