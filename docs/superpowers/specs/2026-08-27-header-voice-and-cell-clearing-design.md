# 按表头念分数 · 纠正后文本显示 · 单元格清除

日期：2026-08-27

## 目标

三块相互独立，按顺序落地，每块跑通测试后再进下一块：

1. 念表头名填分，不再局限于「第几题」
2. 「听到」区只显示纠正后的文本，不再留着听错的原词
3. 补齐单元格清除操作：单格、整行、整列，可撤销

## 一、按表头名念分数

### 现状

`_fill_scores` 是纯位置映射：

```python
idx = int(q) - 1
target = self.model.score_cols[idx]
```

题号 `q` 只能来自 `_HEAD_RE`（`第?[零一二两三四五六七八九十百\d]+[题次]`）。表头文字从未参与匹配，表头叫「程序题」时只能念「第一题」。

### 表头分类

`identify_columns` 拿到 `score_cols` 后，按表头文字把每个分数列分成两类：

| 类型 | 判定 | 匹配方式 |
|------|------|----------|
| 序号型 | 表头形如「第X题」「第X次」 | 精确解析序号（现有 `_HEAD_RE`） |
| 名称型 | 其他任意文字（程序题／作文／选择题） | 表头名精确匹配 + 拼音近似匹配 |

### 切分点优先级

`_split_by_head` 的切分点从只认「第X题」扩展为三条路径，同一段文本内按位置排序后合并：

1. 表头名**精确**出现在句中 → 命中该列
2. 表头名**拼音**近似 → 命中该列
3. 「第X题」序号 → 按位置命中 `score_cols[X-1]`

序号路径保留，念序号和念表头名两条路都通。

### 拼音匹配只对名称型表头启用

「第一题」与「第二题」拼音为 `diyiti` / `dierti`，`difflib` 相似度过高，模糊匹配会串台把分数填到错误的题上。序号型表头本身已有可靠的精确解析，不需要模糊兜底。名称型表头（程序题 vs 选择题）发音差异足够大，模糊匹配安全。

实现上复用 `_find_total_by_pinyin` 已有的滑动窗口做法：按各表头名的字数开窗，逐位置比对拼音，取相似度最高且超过阈值的表头。阈值沿用姓名纠错的 `_NAME_FIX_THRESHOLD`（0.62）量级，单独定常量以便分别调整。

序号型的判定：`_HEAD_RE.fullmatch(表头文字)` 成立即为序号型。

### 返回值语义不变

`extract_score_items` 仍返回 `[(1-based 序号, 分值)]`。表头名命中后换算成它在 `score_cols` 里的序号，`_fill_scores` 及其下游（`_pending_q`、`add_scores` 的 `all(v is None ...)` 判断）一行不改。

### 附带调整

- `_fill_scores` 的提示语「记下第1题」改用表头文字：新增 `_question_label(col)` 返回表头原文，表头叫「程序题」时提示「记下 程序题」
- `build_grade_vocab` 把表头名纳入识别词表（当前 sense-voice 引擎不用词表，保持接口一致）

## 二、只显示纠正后的文本

### 现状

```
recorder → emit("final", 原文) → _handle_event → heard.append(原文)
                                              → _on_text(原文) → handle_text 内部纠正
```

纠正发生在 `state.py:368`（`text = corrected`），结果只 `print` 到日志。界面「听到」区留着听错的原词（「五米」而不是「吴敏」）。

### 改动

`ActionResult` 增加 `heard_text: Optional[str]` 字段，`handle_text` 纠正后填入。`_on_text` 改为**先处理、再显示**，用 `result.heard_text or text` 写「听到」区与「听到：」标签。

| 情形 | 显示 |
|------|------|
| 姓名纠正命中 | 纠正后的姓名 |
| 表头纠正命中 | 纠正后的表头名 |
| 没有任何名字／表头发音接近 | 原文（否则无法判断软件到底听到了什么） |
| 识别为空 | 「这一句没听清」，不变 |

## 三、单元格清除

### 菜单

右键菜单按位置动态构建。现有的「清空该生已填分数」与新增的「清除整行分数」语义重复，合并掉：

```
设为当前学生
─────────
清除此格
清除整行分数（该生所有题）
清除整列分数（全班这一题）   ← 确认弹窗
```

### 作用范围

有选区就作用于选区（行头／列头选中的整行整列、拖选区域都算），没有选区就作用于右键所在的格／行／列。

Delete 与 BackSpace 绑到「清除选中区域」。

### 清除后的连带处理

与语音填分保持一致：压入 `undo_stack`、重算总分、作废 `checked`、触发自动保存。

### undo 分组

`undo_stack` 当前一条记录 = 一个格子（`(stu, col, old)`）。清整列会压入一条/学生，撤销需按等同次数才能全部恢复。

改为一条记录 = 一组变更：

```python
undo_stack: List[List[tuple]]     # [[(stu, col, old), ...], ...]
```

一次操作（一句语音填分、一次清除）压入一组，`undo()` 一次弹出并回滚整组。`_fill_scores` 里几处 `append` 改为累积到本次操作的组内，操作结束时整组入栈。

## 测试

每块都先写失败测试再实现：

- 表头匹配：名称型表头精确命中、拼音近似命中、序号路径仍生效、序号型表头不走拼音（「第一题」不会被匹配成「第二题」）
- 纠正显示：`heard_text` 在纠正命中时为纠正后文本、未命中时为原文
- 清除操作：单格／整行／整列各自的清除结果与撤销恢复
- undo 分组：一次清整列后撤销一次全部恢复
